````markdown

```bash
curl -fsSL https://raw.githubusercontent.com/Orbinuity/AiMan/main/install.sh | sh
```

# On Android (Termux)

```bash
pkg install curl

```

# On Windows

```powershell
irm https://raw.githubusercontent.com/Orbinuity/AiMan/main/install.ps1 | iex
```
````

## Usage

All comands and args

### Global Flags

````markdown
# Version

> Usage: -v, --version

Shows the current AiMan version and exits.

# AMA Version

> Usage: -V, --amaversion

Shows the current AMA version and exits.

# Logging

> Usage: -l, --logging

Enable standard execution logging.

# Extreme Logging

> Usage: -L, --extremelogging

Enable verbose function-level call logging.

# Log File

> Usage: -f, --logfile

Automatically output error logs to a `.log` file.
````
